# Bitcradle

An Eleventy site for Alex A. White’s Palm OS applications and J-Pilot conduits.

## Development

Use Node.js 22.12 or newer (required by the deployment tooling).

```sh
npm ci
npm start
```

Run `npm run build` to generate the static site in `dist/`. Open `dist/index.html` directly for an offline copy, or serve the directory from a static host.

## Cloudflare Workers

`wrangler.jsonc` serves the generated `dist/` directory as a static-assets Worker, with no application server. Wrangler runs the Eleventy build before deploying.

```sh
npm run preview             # local Worker preview
npm run deploy -- --dry-run # validate without publishing
npx wrangler login          # authenticate with Cloudflare
npm run deploy             # publish to the authenticated account
```

Deployment requires access to the intended Cloudflare account. No account ID or custom domain is configured yet; inspect the account's zones and existing DNS records before adding the `bitcradle` subdomain as a Workers Custom Domain. `workers_dev` is enabled for initial deployment checks.

The generated output is ignored by Git. Remove `dist/` before rebuilding after deleting or renaming pages or assets, to avoid publishing stale files. Keep Cloudflare credentials out of the repository; `.env`, `.dev.vars`, and `.wrangler/` are ignored.

## Editing the site

Project descriptions and repository links live in `src/_data/projects.json`. Blog entries live in `src/_data/posts.json`, newest first. Eleventy generates a page for each entry.

## Artwork

The mark and wordmark come from the [Bitcradle brand kit](https://github.com/devalexwhite/Palmlatro/tree/HEAD/brand). The Palmlatro screens come from the [game repository](https://github.com/devalexwhite/Palmlatro). The device frames use Palm product photographs from a [Palm Solutions Group presentation](https://github.com/ardiri/dev-palmos/blob/d25b066f0eb346253f49fc06f80a37bf9099c0ef/!dev_conferences/palmsource2003-seminar/03-licensee_session-palm_solutions.pdf).

The reader screenshots show an example edition generated by Feeds to Plucker and a public-domain World English Bible excerpt compiled with Palm Bible+ Converter.

Departure Mono and IBM Plex Sans are bundled with their licenses in `src/assets/fonts/`.
